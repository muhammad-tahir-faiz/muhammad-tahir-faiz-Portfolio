About

I'm a web developer experienced in building modern, responsive websites and e-commerce stores for businesses and personal projects.

My toolkit spans React, Vite, HTML, CSS, JavaScript and PHP on the development side, and WordPress, WooCommerce, Shopify and Tailwind CSS for content-managed sites and online stores.

Every project gets the same priorities: a clean interface, good usability, responsive layouts, and practical functionality that serves the people using it.

How I work

  • Clean UI first — interfaces that are easy to read and easy to use.
  • Responsive by default — layouts designed for phones, tablets and desktops.
  • Practical functionality — features that help the business, not decoration.
  • Store-ready presentation — product pages and storefronts that present items well.
